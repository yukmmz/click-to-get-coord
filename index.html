使い方

  1. 開く（Ctrl+O）で動画ファイル、または画像ファイル（複数可）を選ぶ。
  2. 自動的に Calibration モードに入る。画像上の2点をクリックし、それぞれの実世界座標を 入力する。x も y も異なる2点を選ぶこと。
  3. 2点入力すると自動的に Add モードに入る。クリックで点を記録する。
  4. 消したい点があれば Delete モード（d）でその点の近くをクリックする。
  5. 保存（Ctrl+S）で出力先フォルダを選ぶと、そのフォルダに全ファイルが書き出される。

キャリブレーションのやり直し

点を打っている途中でも c キー（または Calibration ボタン）でやり直せます。

  • 記録済みのクリック点は消えません。新しい2点が確定した時点で、全点の実世界座標が 新しい変換で計算し直されます（画素座標を保持しているため）。
  • 新しい2点が確定するまで、今のキャリブレーションは有効なままです。1点だけ入れて やめても、前の設定は失われません（a キーで Add に戻れば中断できます）。
  • やり直し中は、前のキャリブレーション点が薄く、新しい点が濃く表示されます。

「作業を再開」とは

保存すると、出力フォルダに session.json（キャリブレーションの2点と変換係数、 フレームごとのクリック点）が書き出されます。作業を再開はこれを読み戻す機能です。

  1. 前回と同じ動画・画像を「開く」で読み込む（画像そのものは session.json に入っていません）
  2. 作業を再開を押して、前回の session.json を選ぶ
  3. キャリブレーションと打った点が全部戻るので、続きから追加・削除できる

用途: 途中で中断したとき、点を打ち足したいとき、キャリブレーションだけやり直したいとき。

保存されるもの

  • coords.mat — MATLAB / scipy で読めるバイナリ（coords_raw, coords_real ほか）
  • coords.csv — 全点を1ファイルにまとめたテキスト
  • plot_frame_XXXX.png — 実世界座標系でのクリック点と、それを結ぶ曲線
  • overlay_frame_XXXX.png — 元画像にクリック点を重ねた検証用画像
  • session.json — 作業再開用の状態
  • README.txt — 上記すべての読み方の説明
